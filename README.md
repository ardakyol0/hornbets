# hornBETS

Private FIFA World Cup 2026 betting platform for 20 friends.

## Setup

```bash
npm install
node server.js
```

Open [http://localhost:3000](http://localhost:3000)

## Admin Access

- Username: `admin`
- Password: `admin123`

## Features

- 48 World Cup 2026 teams with real BetMGM odds
- Each player claims one team (first-come, first-served)
- 1000 coin starting balance for betting
- Decimal odds payouts (`amount × odds`)
- Admin panel to control tournament lifecycle and declare winner
